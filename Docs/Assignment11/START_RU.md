# Assignment 11 — запуск и проверка

1. Открой проект в Unity 6000.6.2f1, дождись импорта, открой Assets/mainmenu.unity.
2. Tools → Assignment 11 → Run Data and Save Checks. Проверка работает с временной папкой и не сбрасывает твой настоящий прогресс.
3. Play → NEW RUN. Уровни строятся из Assets/Resources/Data/Level_01…03.asset общей сценой campaign.
4. Для демонстрации данных останови Play, выбери PlayerStats.asset, поменяй moveSpeed или jumpVelocity, запусти NEW RUN. Меняется сам asset, а не код.

## Проверка HP

Получи урон, оставь 1 HP и пройди через выход первого уровня, собрав требуемые монеты. Второй уровень должен начаться с 1 HP. Открой паузу, выйди в меню и нажми CONTINUE: остаётся 1 HP. Собранные монеты/сердца не возвращаются, уничтоженные враги не появляются заново. Для чистой попытки кнопка RESTART намеренно восстанавливает здоровье и возвращает счёт к началу попытки; это не автоматическое лечение при переходе.

## Три обязательные записи

1. **Inspector + JSON:** сделай скриншот PlayerStats или LevelData в Inspector. После реального прохождения открой Tools → Assignment 11 → Open Save Folder и покажи настоящий save.json. Файл Docs/Assignment11/save.example.json — только пример формата.
2. **Перезапуск на iPhone:** в установленной игре или Web/Safari измени громкость, пройди уровень и сохранись паузой. Для Web дай странице завершить запись. Полностью закрой приложение/страницу, открой снова, покажи CONTINUE, HP, открытые уровни и громкость. Unity Remote проверяет ввод редактора; он не доказывает сохранение установленного приложения.
3. **Повреждение файла:** на тестовой копии/в редакторе закрой игру, скопируй save.json в резервную папку, впиши в save.json заведомо неправильный текст, снова запусти игру. Ожидается безопасный запуск с исходными значениями. Не показывай это как выполненный тест, пока реально не проверишь.

## Меню и сброс

LEVEL SELECT: закрытые уровни не нажимаются, следующий открывается после победы на предыдущем. SETTINGS сохраняет HP-настройку, задержку выстрела, опасности, врагов и обе громкости. RESET PROGRESS → CANCEL сохраняет данные; RESET очищает прогресс/счёт/попытку, оставляя настройки.

Сохранения лежат в Application.persistentDataPath, не в Assets. Для iOS и Web требуются отдельные проверки: это разные хранилища и разные сборки. Safari Private Browsing, очистка данных сайта или смена адреса размещения могут сделать прежнее Web-хранилище недоступным.
