# Исправление управления клавиатурой — 19 ноября 2026

Физические Keyboard.current и Gamepad.current читаются напрямую из Input System. Управление больше не зависит от того, какое устройство PlayerInput автоматически привязал к игроку. Старые OnMove/OnJump/OnFire оставлены как совместимые получатели сообщений, а физический ввод обрабатывается ровно один раз. Экранные TouchStick и JUMP/FIRE продолжают вызывать общие методы.

- A/D или ←/→: движение; одновременные противоположные клавиши дают нулевое направление.
- Space, W или ↑: прыжок.
- X: выстрел.
- Клавиатурное направление имеет приоритет над удерживаемым экранным стиком. Без клавиш работает экранный стик, затем физический gamepad.
- Gamepad: left stick / D-pad, A для прыжка, X для выстрела.

В Unity нажми Play, выбери NEW RUN или CONTINUE, затем щёлкни внутри окна Game — нажатия в Inspector/Console не должны управлять игрой.

Если герой всё ещё стоит, открой Tools → Assignment 11 → Check Keyboard Control во время Play Mode. Команда выводит наличие клавиатуры/игрока, активность контроллера, moveSpeed, HP и timeScale. Пришли эту строку Console и первую красную ошибку, если она есть.

Также старый composite Dpad в дополнительном InputSystem_Actions.asset заменён на 2DVector. Проверки синтаксиса и данных выполнены. Реальный ввод клавиатуры в Unity и на устройстве в этой среде не проверялся.
