# Assignment 12: открыть, проверить и сдать

Проект рассчитан на Unity **6000.6.2f1**. В архиве целый проект, а не отдельный патч: распакуй его в новую папку и добавь эту папку в Unity Hub. Открой `Assets/mainmenu.unity` → Play → NEW RUN. Кликни Game view для клавиатуры: A/D или стрелки, Space/W/Up — прыжок, X — выстрел. На iPhone — MOVE/JUMP/FIRE.

## Проверки в Unity

1. Дождись импорта и убедись, что в Console нет красных ошибок. Не редактируй Library/PackageCache; эти файлы восстанавливает Package Manager.
2. Tools → Assignment 12 → **1. Check Audio Assets and Save**. Здесь проверяются ссылки микшера и клипов, 19 событий, формула громкости и JSON в отдельной временной папке. Затем Tools → Assignment 11 → Run Data and Save Checks.
3. В Play Mode запусти **3. Audit Live Audio Routing**: один SoundPass и AudioListener, все источники направлены в группы. Микшер: **2. Open Mixer**. Индивидуальные клипы можно послушать через Sound Audition.
4. Сыграй: прыжок, монета, урон, лечение и выстрел должны звучать только после реального действия. Подойди к каждому типу врага: предупреждение начинается при подготовке, выстрел/удар — после задержки. У босса отдельные сигналы веера и дождя. Повторные короткие звуки слегка меняются по высоте.
5. Меню → NEW RUN: проверь секундный переход двух тем без резкого обрыва. При переходе L1 → L2 тема уровня продолжает играть, а не начинает первый такт заново. Смерть и проигрыш — два различных звука; финальная победа — отдельная мелодия.
6. Пауза: персонаж стоит, музыка продолжает тихо и приглушённо играть; Resume возвращает прежнюю громкость. Проверь также паузу при сворачивании приложения.
7. Settings: передвинь Music и SFX (видны dB), отдельно проверь 0/mute и максимум. Выставь различимые промежуточные значения, закрой именно приложение/вкладку, открой снова и покажи прежние значения. В Safari проверяй на том же адресе и в обычной вкладке, без очистки данных сайта.
8. Сохрани регрессии: A/D/стрелки двигают, клавиатура и touch прыгают/стреляют; монеты на платформах достижимы; переход с 1 HP оставляет 1 HP; Continue сохраняет монеты/врагов/таймер. Явный Restart начинает попытку с полным HP — это ожидается.

## Windows → iPhone Safari, без Mac

1. В Unity Hub установи для 6000.6.2f1 модуль **Web Build Support**.
2. File → Build Profiles → Web → Switch Platform. Дождись импорта.
3. Tools → Mobile Game → **5. Build Web (Safari)**. Результат: `Builds/Web`.
4. В Windows открой терминал в папке проекта и выполни `py Tools/serve_web.py`. Оставь окно открытым. Разреши Python только для частной сети, если Windows Firewall спросит.
5. Подключи iPhone к тому же доверенному Wi-Fi, открой в Safari напечатанный адрес `http://<IP-компьютера>:8000`. Это не `localhost` телефона. Коснись NEW RUN/CONTINUE для пользовательского жеста, разрешающего аудио браузеру. Проверь системную громкость и выведи телефон из беззвучного режима, если звука нет.
6. Записывай настоящую игру с телефона. Для остановки сервера Ctrl+C. Не открывай index.html напрямую как локальный файл.

Это путь проверки Web на iPhone, а не подписанная нативная iOS-сборка. APK предназначен для Android. Для установки нативного iOS-приложения нужны Xcode/macOS и подпись; одного ZIP/Xcode-экспорта недостаточно. Уточни у преподавателя, подходит ли запись Safari для телефонной части, если он требует именно установленное приложение.

Web: Unity не применяет native AudioMixer lowpass. Поэтому проект смешивает синхронные приглушённые копии тех же тем и плавно меняет gain PauseDuck. В Windows/native iOS работают настоящие Normal/Paused snapshots. Звук, отсутствие щелчков и синхронизацию Web-копий нужно проверить на устройстве.

## Скриншот микшера

Tools → Assignment 12 → 2. Open Mixer. Растяни окно, чтобы были видны **Master, Music, SFX, PauseDuck** и **Normal/Paused** в Snapshots. Выбери Paused, затем PauseDuck: в Inspector должны быть −12 dB и Lowpass 1600 Hz. Сделай реальный скриншот окна, например `Assignment12_AudioMixer.png`. При Play включи Edit in Play Mode при необходимости; exposed MusicDb/SfxDb показывает пользовательскую громкость, а не значение duck.
